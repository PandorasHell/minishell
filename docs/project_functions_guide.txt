–––––––––––––––––––––––––––––––– ENV ––––––––––––––––––––––––––––––––

free_env		--> Libera la memoria alojada en todos los nodos de lista enlazada "t_env".
save_data_env	--> Guarda en una nueva estructura "t_denv" los valores key/value del entorno y la devuelve.
save_env		--> Crea una nueva lista enlazada "t_env" con los valores "t_denv" y "next" para cada variable del entorno.

–––––––––––––––––––––––––––––––– LEXER ––––––––––––––––––––––––––––––––

is_space			--> Comprueba si el caracter facilitado corresponde a algun caracter de espacio.
is_operator			--> Comprueba si el caracter facilitado corresponde a algun operador de shell.
is_quote			--> Comprueba si el caracter facilitado corresponde al caracter de comilla simple o doble.
free_words			--> Libera la memoria asignada para cada nodo "t_lword".
quote_checker		--> Comprueba si hay una comilla de cierre en la cadena. Retorna su posición.
save_word			--> Guarda en un nuevo nodo "t_lword" la cadena de caracteres encontrada. Retorna si encuentra un espacio u operador.
save_operator		--> Guarda en un nuevo nodo "t_lword" el operador de shell encontrado.
split_words			--> Genera una nueva lista "t_lword" sobre la linea facilitada por "readline".
set_lexer_key		--> Asigna un valor "key" a cada nodo de la lista "t_lexer" dentro de la estructura "t_dlexer".
set_lexer_value		--> Crea una nueva lista "t_lexer" en base a la lista "t_lword". 
free_lexer			--> Libera toda la memoria asignada de la lista "t_lexer", incluida la estructura "t_dlexer".
lexical_analysis	--> Funcion controladora para la gestión entre la creación de palabras y el análisis lexico.

–––––––––––––––––––––––––––––––– PARSER ––––––––––––––––––––––––––––––––

free_cmd		--> Libera toda la memoria relacionada a la estructura "t_cmd_data", pero no libera ni esta ni la lista "t_cmd".
final_cmd		--> Genra la lista final de comandos con sus opciones y redirecciones correspndientes. En caso de error libera la memoria relacionada.
create_cmd		--> Gestiona la creación de los valores correspondientes a los nombres, opciones y redirecciones de un comando.
set_cmd_mem		--> Reserva memoria para la lista "t_cmd" y para la estructura "t_cmd_data".
set_cmd_word	--> Reserva memoria para la estructura "t_cmd_name" y asigna el valor "name" del comando relacionado.
					Si hay varios valores "key" con valor WORD seguidos en la lista "t_lexer" estos se generarán como siguientes en la lista "t_cmd_name".
set_cmd_redir	--> Reserva memoria para la lista "t_cmd_red" y para la estructura "t_cmd_dred", y asigna los valores "where" y "type" del comando relacionado.
					Si hay varios valores "key" con valor REDIR seguidos en la lista "t_lexer" estos se generarán como siguientes en la lista "t_cmd_redir".
set_cmd_value	--> Gestiona el tipo de dato que se va a genrar dentro de "t_cmd_data" teniendo en cuienta el valor "key" de "t_lexer". 
status_pipe		--> Comprueba si el valor devuelto en "set_cmd_value" corresponde a PIPE y avanza una posición si es posible.
status_redir	--> Comprueba si el valor devuelto en "set_cmd_value" corresponde a REDIR y avanza una posición si es posible,
					en caso contrario libera toda la mmoria asignada hasta el momento dentro de "t_cmd".
